# Deploy Voltixa to Netlify

Voltixa uses Next.js server rendering, route handlers, Supabase authentication,
admin APIs, and secure server-only environment variables. It must be deployed
as a Next.js project through Netlify's build system or CLI. Do not drag only
static HTML files into Netlify Drop because account, admin, API, and dynamic
catalog routes would not work.

## Recommended: deploy from Git

1. Push this project to a private GitHub, GitLab, or Bitbucket repository.
2. In Netlify, choose **Add new project → Import an existing project**.
3. Netlify will read `netlify.toml`:
   - Build command: `npm run build`
   - Publish directory: `.next`
   - Node.js: 22
4. Add the environment variables listed below under:
   **Project configuration → Environment variables**.
5. Deploy the site.

## Required environment variables

```text
NEXT_PUBLIC_SITE_URL=https://your-site.netlify.app
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
NETLIFY_NEXT_SKEW_PROTECTION=true
```

Add payment, courier, and webhook variables only when those providers are
configured. Never commit the service-role key or other secrets.

## Supabase production settings

After the first Netlify URL is available:

1. Set `NEXT_PUBLIC_SITE_URL` to the final Netlify/custom-domain URL.
2. In Supabase Authentication URL configuration, set the Site URL to the same
   HTTPS URL.
3. Add these redirect URLs:
   - `https://your-site.netlify.app/account`
   - `https://your-site.netlify.app/**`
4. If a custom domain is added later, add its HTTPS URLs as well.

## Manual CLI deployment

From the extracted project folder:

```bash
npm ci
npx netlify-cli login
npx netlify-cli init
npx netlify-cli build
npx netlify-cli deploy
npx netlify-cli deploy --prod
```

Run deploy commands from the project root so Netlify can package the Next.js
server functions generated by its OpenNext adapter.
